# D&D 5e Помощник Новичка — Финальный план реализации

Премиальный, дружественный к новичкам цифровой ассистент для D&D 5e. Веб-приложение без зависимостей (HTML5 + CSS3 + ES6 Modules): мгновенная загрузка, полная оффлайн-работа, адаптивная мобильная вёрстка.

## User Review Required

> [!IMPORTANT]
> **Язык интерфейса:** Русский с английскими D&D-терминами в скобках.
> Примеры: «Сила (STR)», «Класс Брони (AC)», «Спасбросок (Saving Throw)», «Бонус Мастерства (Proficiency Bonus)».
> Все описания, подсказки и объяснения — на русском. Механические аббревиатуры (STR, DEX, AC, HP, DC) остаются на английском, т.к. они универсальны в D&D-сообществе.

> [!IMPORTANT]
> **SOTA Level-Up Flow:** Повышение уровня реализовано как пошаговый мини-визард (по аналогии с PrismScroll / D&D Beyond), а не простая кнопка. При каждом нажатии «Повысить уровень» игрок проходит:
> 1. Выбор HP (бросок кубика или среднее значение)
> 2. Новые фичи класса (показываются автоматически)
> 3. На уровнях 4/8/12/16/19 — выбор ASI (+2 к характеристике или черта)
> 4. Для заклинателей — новые заклинания и ячейки
> 5. Итоговый экран с diff-сравнением «было → стало»

#### [NEW] [js/state.js](file:///d:/Code AI/Projects/AntigravityTest/js/state.js)
Реактивное состояние с подпиской на изменения:

```js
const state = {
  characters: [],         // Массив всех персонажей
  activeCharacterId: null,
  currentScreen: 'home',  // 'home' | 'wizard' | 'sheet'
  wizardData: {},          // Временные данные создания
  rollLog: [],             // Последние 50 бросков
  activeTab: 'attacks'     // Активная вкладка на листе
};
```

- `subscribe(callback)` — подписка на изменения. Компоненты подписываются на свои секции
- `setState(patch)` — мержит изменения, вызывает колбэки, автосохраняет в localStorage (debounced 300ms)
- **Точечный ре-рендер:** каждый компонент подписывается на конкретные поля состояния (например, `combat` слушает только `character.hp`). При `setState` вызываются только затронутые компоненты, не перерисовывая весь DOM
- **Защита фокуса:** перед ре-рендером запоминается `document.activeElement`, после — фокус восстанавливается
- `exportCharacter(id)` → скачивает `.json` через `Blob` + `URL.createObjectURL`
- `importCharacter(file)` → `FileReader` + валидация схемы + добавление
- Версионирование: `{ version: 1, ...data }` для будущих миграций
- `try/catch` на `localStorage.setItem` с toast-уведомлением при переполнении

#### [NEW] [js/dice.js](file:///d:/Code AI/Projects/AntigravityTest/js/dice.js)
Движок бросков:

**Функции бросков:**
- `roll(sides)` → случайное 1–sides
- `rollWithMod(sides, modifier, label)` → `{ roll, modifier, total, label, timestamp, isCrit, isCritFail }`
- `roll4d6DropLowest()` → для генерации характеристик в визарде
- `rollMultiple(count, sides, modifier)` → для урона (2d6+3)

**Аудио (Web Audio API):**
- Создание `AudioContext` при первом взаимодействии пользователя
- **Noise buffer:** `createBuffer` заполненный случайными сэмплами → `BiquadFilterNode` (bandpass 800–2000Hz) → `GainNode` (быстрая атака, затухание 300мс) → `destination`
- Результат: короткий «стук кубиков» без внешних файлов
- Кнопка-переключатель звука (🔊/🔇)

**Анимация:**
- CSS-класс `.rolling` → `diceShake` keyframe 400мс
- По завершении: toast с результатом
- Крит (нат. 20): золотое свечение + вибрация (если мобильное)
- Крит. провал (нат. 1): красная вспышка

**Лог бросков:**
- Массив последних 50 бросков с временем, формулой, результатом
- Боковая прокручиваемая панель
- Кнопка «Очистить лог»

**Шаг 4 — Навыки и Владения:**
- Чекбоксы для навыков разрешённых классом
